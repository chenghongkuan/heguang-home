# 和光 · 新中式居所

以 Blender 设计的两卧一书房住宅为基础，提供可在电脑与手机浏览的交互式三维模型与设计图集。

**在线访问：[和光 · 3D 空间](https://chenghongkuan.github.io/heguang-home/)**

- 全屋鸟瞰、正交平面、客餐厅与两间卧室，以及书房、整墙电视收纳、主卧衣柜、书房书柜和二楼窗景，共 11 个视角；书房东侧原门洞封墙，南侧走廊门向书房内开启，书桌改至东墙。
- 65 英寸电视嵌入整墙收纳柜，主卧卫生间保持原尺寸和洁具，卧室空地设 3.15 米长、67 厘米总深的整墙移门衣柜，柜门与窗边墙垛齐平；床头恢复靠图左侧墙，采用 1.35 × 1.90 米床，图上床侧留作主要进出通道。书房书柜也加深至 57 厘米，与窗边墙垛齐平。
- 二楼窗外为三维河道与花园，可切换外景显示。
- 旋转、缩放、平移、双击定位；网页默认墙体剖切高度为 2.85 m，可调节剖切高度、切换顶面及房间标注。
- 手机单指旋转、双指缩放与移动，支持当前视图截图保存。
- 11 张设计效果图、1 张房间标注平面，以及包含储物尺寸说明的 PDF 图册。

## 本地查看

不需要安装 Node.js 或构建依赖：

```sh
python3 -m http.server 8000 --directory site
```

浏览器打开 `http://localhost:8000`。请通过 HTTP 服务查看，直接双击 HTML 不能加载 ES 模块和模型。

## 文件

- `site/assets/home.glb`：从 Blender 4.5.3 LTS 导出的全屋及二楼河园模型，24,993,228 字节（约 23.8 MiB），独立网格共 368,312 个三角形（实例展开数量另计），单位米，Y 轴向上。
- `site/app.js`：Three.js 查看器、11 视角、剖切、外景与图集逻辑；将静态几何按材质合并，减少绘制调用。
- `site/assets/`：12 张 WebP 图片、缩略图、图集索引和 PDF 图册。
- `site/vendor/`：固定版本 Three.js 0.186.1 及所需模块，运行时不依赖外部 CDN；MIT 许可见 `THREE-LICENSE.txt`。
- `.github/workflows/deploy-pages.yml`：推送 `main` 后发布 `site/` 到 GitHub Pages。

## 设计与显示说明

两位长辈分房居住。主卧已确认设于图左下的长辈卧室 A，图中下为长辈卧室 B。主卧按用户选择配置 1.35 × 1.90 m 床，床头恢复靠图左侧实墙、床尾朝右；长辈卧室 B 保留 1.50 × 2.00 m 床。主卧右侧整墙衣柜长 3.15 m、总深 0.67 m，柜门正面与飘窗右侧墙垛齐平，三格挂衣、一格层板，四扇双轨移门。第二扇门连同木框和拉手沿柜宽横移 0.74 m，模型展示滑开状态；门扇不向过道外摆。

主卧主要从图上床侧上下床并去卫生间。完整床尾至衣柜约 0.5525 m，仅为局部取衣窄距；图上床侧至房门连续扫掠边约 1.43 m。图下床侧至飘窗木台约 0.3575 m、床头至左墙约 0.020 m，分别为靠窗留空和安装缝，不作为通道。滑门省去外摆占用，取衣站位仍占用柜前空间。原矮隔墙和西侧柜撤去，卫生间尺寸、洁具和入口保留。

图上为书房，东侧原门洞封墙，南侧靠长辈卧室 B 的走廊门向内开启。东墙 1.68 × 0.64 m 书桌、北端朝西开启的抽屉柜与北飘窗阅读区保留。西侧 2.98 m 书柜总深 0.57 m，正面与飘窗左侧墙垛齐平；书椅向桌下收进，向后拉出 0.40 m 时，椅背至书柜约 0.95 m。客厅采用包围 65 英寸电视的整墙收纳柜。柜体尺寸属于模型外包尺寸，不能直接作为内部净尺寸或订货尺寸。

卧室采用蜜棕橡木地板，客餐厅采用暖灰米色哑光砖。家具采用细木纹胡桃木，软装表现亚麻织纹；不布置松散地毯。GLB 内嵌图像 PBR 贴图，保留木纹、拼缝、粗糙度与法线细节，网页使用各向异性过滤改善斜视纹理。

临河面已确认在图下方，即客厅大窗和两间长辈卧室窗这一侧，河道与花园沿该侧平行展开。室内地坪暂按高于花园 3.50 m 表达二楼观察高度；河宽、离楼距离、河岸、植物与标高仍为概念假设，尚未现场测量。

交互模型使用实时 PBR 照明，光影与 Blender Cycles 高清效果图略有差异。剖切作用于建筑、门窗与相关挂饰，独立家具和储物柜保持完整；平面视角隐藏外景，便于查看室内布局。书房门位调整为概念方案，门套和走廊净宽需现场复核。

本项目是概念设计，非施工图。净高暂按 2.80 m、吊顶下表面按 2.68 m；尺寸、结构、机电、柜体安装与适老细节需现场复核。局部通行空间有限；图面上、下、左、右不代表实际地理朝向。

紧凑空间采用移门参考 [IKEA 的小卧室收纳方案](https://www.ikea.com/us/en/rooms/bedroom/gallery/a-modern-small-bedroom-where-you-can-show-off-your-best-side-pxm81fd4900755a11ed8736ff69fe285fe9/)。本版恢复原西墙床头方向，并以用户选择的 1.35 × 1.90 m 小床留出床尾空间。卫生间保持原尺寸、洁具和入口；柜体端部避开原房门与飘窗，柜顶以收口板接至吊顶。
